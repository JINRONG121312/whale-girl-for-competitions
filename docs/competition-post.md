## 二、作品是什么

**一句话：这是一个装在任何网页左下角的 Q 版大肥鱼挂件——独立开发者、学生和博客作者在写代码或自习时，抬头就能看到她摸鱼、被龙虾娘查岗，并能用弹幕和她互动。**

她不是一张会动的贴图，而是一个有作息的室友：

- 大部分时间在写代码，每 20 秒摸一次鱼；
- 摸鱼时可能被龙虾娘查岗，被抓扣 6 个鱼币，但攒钱上限同时 +6；
- 4 秒内连戳 5 次会生气，停手 10 秒才消气；
- 凌晨 2 点到 5 点会睡着，谁都不理；
- 会读页面上的弹幕，按关键词接话；你一发弹幕，她头顶的气泡会归这段对话 15 秒，期间的摸鱼和日常台词全部排队；
- 可以拖到屏幕任意位置，位置会被记住；拖到屏幕右半边，气泡会自动换边，不会被顶出屏幕。

整个挂件 gzip 后约 **15 KB**，零运行时依赖，主角色直接内联在脚本里。桌面端是一个能互动的角色；手机端她收成一个圆头像，点一下展开小卡片——照样能投喂，还能点「摸鱼呢？／夸夸你／老板来了」让她用同一套规则接一句，一个请求都不发。

## 三、为什么做

最开始，我只是想给自己的小博客加一个看板娘。

那台服务器是 2 核 2G、3 Mbps 带宽，而主流的 Live2D 方案，一个模型加贴图通常要 1–3 MB。为了一个角落里的装饰，让访客对着白屏多等几秒，我觉得不划算。

所以最后做成了一个很“省”的方案：手绘 SVG + CSS 动画。她不会跟着鼠标转头，也做不了骨骼动画，但她几乎不增加页面负担，任意分辨率都不糊。**做加法谁都会，难的是知道自己不该加什么。**

真正让我想把它做成参赛作品的，是那个“惩罚即成长”的设定：

> 被抓到扣 6 个鱼币，但攒钱上限同时涨 6。你越被抓，罐子越大，越能装。

它把“犯错”从一个需要避免的负反馈，变成了一个带点黑色幽默的正反馈。我想用一个很小的作品，讨论一件挺大的事：**一个网页里的角色，能不能不靠堆资源，也让人觉得它真的在陪你。**

## 四、怎么用（5 步以内）

1. **打开作品链接**（桌面浏览器体验最完整）。页面左下角就是她，右边是实时观测窗和遥控器。
2. **点她一下**：摸摸她 +8 鱼币，她会甩尾游开；卡片里的「打赏 +8」是另一个入口，手机端也能用。**4 秒内连点 5 次**，她会生气，停手 10 秒后自己消气。
3. **点“召唤龙虾娘”**：进入查岗演示，点她试试 15% 的逃脱概率（窄屏时点开卡片点「打赏」也一样）；失败会扣 6 鱼币，但上限 +6。
4. **在观测窗里发一条弹幕**，或者点“bug / 老板 / 摸鱼 / 夸夸”快捷词，看她按关键词接话——气泡会锁在这段对话上 15 秒。
5. **拖动她换位置**；想换一套作息，就到“定制”里调四个参数并应用。手机端她收成圆头像，点一下展开卡片，可以投喂、可以点词接话；查岗和连戳也照常生效，只是入口换成了卡片里的「打赏」按钮。

> 小提示：她攒满一罐会直接换班，没有“下班”；如果你在凌晨 2–5 点打开，她大概率已经睡着了。

## 五、用 Qoder 做出来的过程

### 1. 先读仓库，再决定怎么讲

我把原来的 GitHub 仓库交给 Qoder。它通读了 README、技术报告、复盘文和 `src/whale-girl.js`，把项目里最值得被记住的四件事提炼出来：**15 KB、零依赖、有限状态机、事件解耦**。

这一步没有急着写代码，而是先确定“评委打开页面后，先看到什么、能马上做什么”。

### 2. 重绘角色，确定“深海观测窗”的叙事

最开始我想直接借用最近很火的那只鲸鱼娘当桌宠主题，Qoder 在生成之前提醒我：那份素材是 **CC BY-NC-SA**，不能搬进参赛作品。这个提醒是有用的，于是方向改成——**重绘一只原创的 Q 版大肥鱼**，保留耳机、笔记本、摸鱼、查岗这些已有玩法，把动作一套一套补齐（甩尾、眯眼、飘 z z、接鱼币、炸毛、打瞌睡）。

角色是重新画的原创 SVG，没有搬用任何第三方同人素材。展示站因此有了一个统一的视觉母题：左边是浅色海面，讲她是谁；右边是深色观测窗，放她的实时生命体征和遥控器。

这一轮从角色到站点的连续工作大约跑了一小时，模型是 Qw3.8-Flash。过程可视化把每一步都留在了时间线上，我只要判断“这个要不要”，不用自己一行行去补。

### 3. 只增强挂件，不重写挂件

原版已经能跑，所以这次只加了两个很小的口子：

```js
// 读取页面在脚本加载前注入的参数
var CFG = window.WG_CONFIG || {};
var SLACK_EVERY = Math.round(num('slackEvery', 20, 5, 120));
var BOSS_CHANCE = num('bossChance', 0.7, 0, 1);
var PENALTY     = Math.round(num('penalty', 6, 0, 30));
var CAP_STEP    = Math.round(num('capStep', 6, 0, 30));

// 演示页专用：外部可召唤一次查岗；正式接入时不需要
document.addEventListener('wg:boss', function () {
  if (DEEP_NIGHT || isCompact() || game.angry) return;
  game.phase = 'slack';
  game.bossActive = true;
  game.bossLeft = 30;
  say(pick(LINES.boss), ACTS.boss);   // 动作与台词分两行显示
  render();
});
```

参数注入让“定制”滑块能真正作用在左下角的她身上；`wg:boss` 让“召唤龙虾娘”不是一段假动画，而是真的进入查岗状态。

第二步是把我自己在 Hexo 博客上跑了一段时间的那版改动搬回来——同一作者的另一份构建，不是别人的素材：

- 气泡从卡片里搬出来，变成贴在她头顶的独立贴纸，**说话和动作分两行**（「（眯起眼睛，假装在看文档）／屏幕亮着就算在工作」）；
- **一次对话锁定气泡 15 秒**，期间日常台词、摸鱼提示全部让路，只有你主动的操作才能打断；
- **打赏与「摸摸」拆成两个入口**，手机端也能投喂；
- **拖拽按控件真实尺寸夹紧**，靠右时气泡自动翻转，不再顶出屏幕；
- 手机端卡片里加了三个「点词接话」按钮，直接复用挂件的关键词回复规则，不发请求。

博客那版还接了一个 `/api/chat` 的 AI 聊天后端。这次**没有搬过来**：公开站点是 HTTPS，那个服务只有 HTTP 且没有 CORS，浏览器跨不过去；而且为了一个角落里的挂件加一条服务端链路，跟她“小、省、解释得清”的设定相反。这个方向留给以后——**知道不加什么，和知道加什么一样重要。**

### 4. 把“能看”做成“能玩”

展示站不是一张产品说明书，它本身就是一个可操作的工作台：

- 实时遥测：从挂件的 `data-*` 属性、状态文案和动作行里读出她在干什么，同步到观测窗、气泡和状态机高亮；
- 弹幕：输入或点快捷词，真的派发 `wg:danmaku`，她真的会接，还会把气泡锁在这段对话上；
- 定制：四个滑块实时生成 `window.WG_CONFIG` 和接入代码，应用后地址栏参数会跟着变；
- 手机端：收成头像、点开卡片、投喂、点词接话，查岗与连戳改走卡片里的打赏按钮；
- 接入：一键复制两段代码，粘到任意静态页面就能用。

### 5. 在浏览器里逐项验收，再部署

本地起静态服务后，我用无头浏览器以桌面 1440px 和手机 390px 两套视口跑了 **50 项交互检查**：打赏与摸摸两个入口、气泡两行文案、气泡容器不再挂滚动条、15 秒对话锁定与到期释放、查岗触发与一次点击结算、一次摸鱼不重复查岗、弹幕关键词回复、连戳生气与 10 秒消气、拖拽夹紧与气泡翻转、位置持久化、地址栏参数是否真的作用到挂件、窄屏收成头像与展开卡片、窄屏的查岗与连戳……50 项全部通过，两套视口都没有横向溢出，控制台无报错。

最后用 Qoder Sites 发布为公开站点，让评委打开链接就能直接体验。

## 六、原创与许可

- **角色、SVG、代码、文案、截图均为原创**，没有搬用任何第三方同人素材。
- 原版鲸鱼娘挂件是我本人在参赛前完成并公开在 GitHub 的项目；这次参赛版按“Q 版大肥鱼”的方向重新绘制了角色，并新增了参数注入、`wg:boss` 演示事件、展示站、实时遥测、弹幕、定制器与接入代码生成。
- 这次搬回来的交互改动（独立气泡、动作分行、对话锁定、打赏拆分、拖拽夹紧、手机端点词接话）来自**我自己博客上的另一份构建**，同一个作者的代码在两份构建之间搬运，不构成搬运他人作品。博客那版的 AI 聊天后端没有搬过来，原因写在第五节。
- 代码与资产采用 **PolyForm Noncommercial 1.0.0**：个人、学习、公益可免费使用；商业用途需另行授权并分成。
